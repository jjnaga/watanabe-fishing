# Avoiding the "AI Smell" in Design

## The Problem

AI-generated sites often have a recognizable "vibe" - technically correct but soulless. They look like:
- Template sites
- Overly symmetric
- Generic stock photo energy
- Safe but boring
- "I've seen this 1000 times"

## How to Fight It

### 1. Asymmetry & Tension

**Don't:**
```
[    CENTERED HEADING    ]
[  perfectly centered text  ]
[      centered button      ]
```

**Do:**
- Left-align most text
- Let elements have different weights
- Create visual tension (big thing next to small thing)
- Not everything needs to be in a neat grid

### 2. Real Photography Rules

**Don't:**
- Placeholder images that feel stock-y
- Over-processed, HDR-looking photos
- Generic "happy people fishing" vibes

**Do:**
- Use Jay's actual photos (even if not "perfect")
- Imperfect = authentic
- Real catches, real moments
- Candid > posed

### 3. Typography with Personality

**Don't:**
- Default system font with default sizes
- Every heading the same weight
- Perfectly even spacing everywhere

**Do:**
- Pick a font with character (but still readable)
- Mix weights intentionally (light + bold contrast)
- Let some text be bigger than "normal"
- Headlines can have personality

### 4. Color Restraint

**Don't:**
- Rainbow gradients
- Every section a different background color
- Teal + coral + purple + gold (the AI palette)

**Do:**
- One color, used well
- Mostly black/white/gray with color as accent
- Let photos provide color
- Dark mode is fine but don't force it

### 5. Copywriting That Sounds Human

**Don't:**
```
"Experience the ultimate fishing adventure
of a lifetime with our expert guides!"
```

**Do:**
```
"Jay's been fishing these waters for 20 years.
He'll teach you everything you need to know."
```

- Write like you talk
- Short sentences
- No corporate speak
- Specific > generic

### 6. Spacing & Rhythm

**Don't:**
- Every section exactly 80px padding
- Perfect mathematical consistency
- Elements that feel "placed by algorithm"

**Do:**
- Vary section heights based on content
- Let breathing room happen naturally
- Some things closer, some farther
- Visual rhythm, not visual metronome

### 7. Details That Don't Scale

**Don't:**
- Every button the same
- Every card identical
- Pixel-perfect repetition

**Do:**
- Small variations that feel intentional
- Handcrafted touches
- One section that "breaks the rules" slightly

### 8. Restraint

**Don't:**
- Animations on everything
- Scroll effects everywhere
- Parallax because you can
- Loading spinners with personality

**Do:**
- Static is fine
- One subtle animation max (maybe hover states)
- If it moves, it should have a reason
- Fast > fancy

## The Litmus Test

Would this site feel out of place if Jay texted the link to a friend?

- Too polished = suspicious
- Too generic = forgettable
- Too fancy = trying too hard

**Target:** "Oh nice, Jay got a website. Looks legit. Let me book."

## Specific Anti-Patterns to Avoid

1. **Hero with gradient overlay + centered white text** (everyone does this)
2. **Three columns of icons with features** (the AI special)
3. **Testimonial cards with quotation mark graphics** (overdone)
4. **"Ready to get started?" CTA section** (generic)
5. **Wave SVG dividers between sections** (2019 called)
6. **Floating animation on scroll** (please no)

## What To Do Instead

- Let the photo BE the hero (text can be smaller, off to side)
- Features as a simple list, not icon cards
- Testimonials as plain text with names
- CTA that's specific: "Book your 4-hour session"
- Clean section breaks (whitespace or simple line)
- Nothing floats, nothing bounces
